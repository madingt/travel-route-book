# 用 iPhone 镜像把行程落进高德 App

最佳交付形态：手机高德里一条**私密路线**，按天分组（D1…Dn）、组内按游览顺序排好，出门点哪个导航哪个。

> 以下界面路径和坑都是 2026 年 10 月实测记录。高德 App 改版后菜单位置可能变化：**先截图看清当前界面再操作，不要凭记忆点坐标。**

## 前提（不满足就退回多点地图链接 + 让用户手动收藏）
- Mac 上有「iPhone 镜像」，iPhone 与 Mac 同一 Apple ID、在附近；部分地区不提供 iPhone 镜像。
- Claude 桌面应用开启了 Computer use，本会话能用 computer-use 工具。
- 手机上的高德**已经登录**——这正是用 App 的好处：不用再扫码，也不碰账号密码。

## 开工前（一次说清，省掉后面大量折腾）
- 请用户在高德 App 设置里**关闭「截屏后触发分享」**。否则 Agent 每截一次镜像画面，iPhone 都当成截屏，高德弹出「截图分享」面板，层层叠加、挡住操作。若已发生，提醒用户检查相册里有无多余截图（不要替用户动相册）。
- Mac 上 App 名是中文「**iPhone镜像**」（bundle id `com.apple.ScreenContinuity`），按英文名 resolve 会找不到。
- 镜像窗口显示「iPhone 使用中」：请用户锁屏。显示「解锁 iPhone」：点「连接」，需要时请用户在 Mac 上完成验证。
- computer-use 授权闲置 30 分钟会过期，需要重新 resolve + request access。

## 操作要点
- **回主屏/找 App**：用菜单「显示 → 主屏幕 / App切换器 / 聚焦」，聚焦里输入「高德地图」再点图标。别靠手势。
- **输入文字用后台模式的 app_type**：可直接输入中文。全屏模式的 type 会被 Mac 输入法吞成拼音乱码。空格可能丢失，组名/备注用「·」「+」代替空格。
- **滚动基本不可用**（滚轮、拖拽都常失效）。绕开滚动：
  - 加地点用「搜索」而不是在长列表里找；
  - 从收藏夹批量勾选时只勾当前屏可见的；
  - 「分组管理」左侧栏点组名可直接跳到该组；
  - 把条目「跨组移动」出第 1 组，第 1 组变短，后面的条目自然露出来。
- 「无法从 Mac 使用 iPhone 麦克风」弹窗：点「好」，常在切页时出现。
- 全屏模式和 app_* 后台模式坐标系不同。尽量全程用 app_* 工具，只在后台点不动时才申请全屏控制。
- 截图要省：关闭弹窗、点按钮、再截图放在同一个 batch 里；点击后先确认画面稳定再点下一步。

## 建分天路线
1. 我的 → 收藏 → 顶部「路线」→「我创建的」→「创建路线」→ 填标题（如「<城市>旅行」），**保持「私密」**（公开需用户明确同意）→ 完成。这条路线同时出现在「我创建的收藏夹」里，也满足「建一个收藏夹」的需求。
2. 「添加地点」三种来源：
   - **收藏夹**：多选勾选，**添加顺序 = 勾选顺序**（不是列表顺序），按 D1-1、D1-2… 依次勾。
   - **搜索**：输入「店名 + 路名/片区」，核对地址后点右侧☆；☆变实心并提示「收藏成功」才算加上。**加完等一两秒再清空搜索框**，太快清空会丢点（实战 11 个丢了 6 个）。
   - 地图选点 / 照片加点：照片加点和「导入规划」会打开**用户相册**，未经用户同意不要用。
3. 加完回路线页看「N 个地点」核对总数。搜索结果里的☆状态**不可靠**，不能用来判断是否已在路线里。
4. 「排序分组」→「分组管理」→「添加组」建到 Dn；点组名旁✎改名（≤18 字），如「D2·周六·<片区>+<活动>」。
5. 「跨组移动」：勾选条目 → 右下角移动按钮 → 选目标组。**新加的地点会进入当前所在的组**，加完要移到正确的天。进入移动模式后勾选框位置会变，先截图再点，点完放大核对勾的是不是对的。
6. 组内顺序用右侧拖柄调整。最后逐组核对：每组地点、顺序、总数与 `trip.json` 一致。
7. 退出时确认路线页的起终点与总数；交付时告诉用户入口：「收藏 → 路线 → 我创建的 → <行程名>」。

## 只要收藏夹、不要路线时
- 收藏 → 地点 →「创建收藏夹」；或在地点详情「⋮ → 将地点添加到」勾选目标收藏夹。取消勾选即从该收藏夹移出。
- 误加的地点：路线详情里该条「⋮ → 将地点添加到」取消勾选当前路线即可移除（不影响默认收藏夹）。

## 不要做
- 未经同意打开用户相册、把路线设为公开、删除用户已有的收藏。
- 没关「截屏后触发分享」就开始大量截图。
- 搜索加点后立刻清空，丢点了却不核对总数。
